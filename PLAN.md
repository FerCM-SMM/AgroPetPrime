# AgroPet Pr1me — Plano de Projeto

> Cliente: AgroPet Pr1me
> Tipo: Site institucional + e-commerce WhatsApp-first
> Orcamento: R\.000 (meta: R\.000 lucro, R\.000 ferramentas)
> Meta mensal: 300 pedidos
> Stack: Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + Supabase + N8N

## Resumo Executivo

A AgroPet Pr1me e um pet shop que comercializa racões, medicamentos, acessórios, equipamentos, brinquedos, higiene e vestuário para cães, gatos, passarinhos e cavalos. O site funciona como catalogo + carrinho de compras, onde o cliente monta seu pedido e ao finalizar, o pedido é enviado via WhatsApp para a loja.

## Objetivos

1. Divulgar produtos — Catálogo completo com categorias, busca, filtros
2. Gerar pedidos via WhatsApp — Checkout que envia mensagem formatada
3. Capturar leads — Formulário de cadastro + consentimento LGPD
4. Base de clientes — Banco de dados com histórico de pedidos
5. Analytics para o lojista — Dashboard com métricas
6. Marketing automatizado — N8N para campanhas
