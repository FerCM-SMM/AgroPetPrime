# Manual do Administrador - AgroPet Pr1me

## Acesso ao Painel
1. Acesse /admin no site
2. Faça login com suas credenciais de admin
3. O dashboard sera carregado com as metricas principais

## Dashboard
- Pedidos do mes (total e por status)
- Clientes ativos
- Total de produtos cadastrados
- Faturamento estimado

## Gestao de Pedidos
1. Acesse /admin/pedidos
2. Altere o status conforme o andamento
3. Confirme os pedidos no WhatsApp primeiro

## Gestao de Clientes
1. Acesse /admin/clientes
2. Exporte a lista para CSV
3. Identifique clientes frequentes para campanhas

## Analytics
1. Acesse /admin/analytics
2. Visualize graficos de pedidos por dia
3. Analise ticket medio e frequencia de compra
